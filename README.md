# Sound Vision — визуальная индикация источников звука

Accessibility-мод для **S.T.A.L.K.E.R.: Anomaly** (1.5.1 / 1.5.2 / 1.5.3).
Создан для слабослышащих игроков: игра рисует **расходящиеся кольца прямо на экране** в точке
любого источника звука — в том числе **сквозь стены**. Размер кольца уменьшается с расстоянием
до источника, всё настраивается в **MCM**.

---

## Что вы увидите

| Событие | Визуал |
|---|---|
| Кто-то идёт/бежит (в т.ч. за стеной) | жёлтые кольца в точке шагов |
| Кто-то говорит, кричит, стонет | белые кольца |
| Выстрелы, взрывы, гранаты | красные кольца |
| Мутанты (шаги, рычание, атаки) | фиолетовые кольца |
| Физика: выпавшие предметы, двери, столкновения | синие кольца |

- Кольцо **расширяется и гаснет** как волна (1–3 волны на один звук, настраивается).
- Чем **дальше источник — тем меньше кольцо** (настраивается: базовое расстояние и минимальный размер).
- Если источник **за краем экрана** или за спиной — маленькое кольцо прижимается к краю экрана:
  видно, с какой стороны звук.
- Цвет кольца задаётся категорией звука; яркость — общая настройка.

## Как мод узнаёт о звуках

Мод **не перезаписывает ни одного файла игры** — только добавляет свои. Используются три источника:

1. **`npc_on_hear_callback`** (ванильный колбэк Anomaly) — «слух» движка: когда любой NPC или
   монстр **услышал** звук, движок сообщает его тип (выстрел/шаг/голос/физика — строки из
   ogg-комментариев, напр. `WPN_hit`, `MST_attack`) и позицию. Это даёт выстрелы, голоса,
   монстров и физику на большой дальности.
2. **Опрос движения** NPC/мутантов рядом с игроком (каждые 250 мс): объект сместился — значит
   он «шагает». Это гарантирует кольца для **идущего за стеной сталкера**, даже если звук его
   шагов не дошёл до ушей других NPC.
3. **`actor_on_footstep`** (ванильный) — собственные шаги игрока. По умолчанию **выключено**
   (свои звуки вы ощущаете и так), включается в MCM.

## Установка

### Mod Organizer 2
1. Скачайте архив `SoundVision_v1.0.zip`.
2. В MO2: вкладка *Archives* (справа) → *Install From file* → выберите архив.
3. Убедитесь, что мод включён и стоит **выше** модов, которые могли бы менять
   `sound_vision.*` (их нет — конфликтов по именам нет).
4. Запустите игру.

### Вручную
Скопируйте папку `gamedata` из архива в корень игры (там, где лежит `AnomalyLauncher.exe`)
с объединением папок. Перезаписи существующих файлов не будет.

### Требования
- **MCM (Mod Configuration Menu)** — опционально. Без него мод работает с настройками
  по умолчанию (включён, дальность 45 м).
- Modded exes не требуются: всё построено на ванильных колбэках Anomaly 1.5.x.

## Настройки (MCM → Sound Vision)

### Общие
| Параметр | По умолчанию | Описание |
|---|---|---|
| Включить мод | вкл | показать/скрыть все кольца |
| Показывать свои звуки | выкл | кольца для собственных шагов/выстрелов игрока |
| Дальность обнаружения | 45 м | звуки дальше не показываются (5–100) |
| Время жизни волны | 1.2 с | как долго расширяется и гаснет одно кольцо |
| Пауза от одного источника | 0.3 с | анти-спам: не чаще одной волны за это время от одного источника |

### Размер и анимация
| Параметр | По умолчанию | Описание |
|---|---|---|
| Размер кольца | 96 px | размер кольца у близкого источника (виртуальные пиксели HUD) |
| Базовое расстояние | 8 м | на этом расстоянии кольцо имеет полный размер |
| Минимальный размер | 0.12 | предел уменьшения для самых дальних звуков |
| Волн на один звук | 2 | 1–3, «сонар» |
| Яркость | 0.85 | общая непрозрачность |

### Типы звуков
Пять переключателей категорий: выстрелы/оружие, голос/речь, шаги/движение, мутанты,
физика/прочее. Каждую категорию можно отключить по отдельности.

> **Как подобрать размер под себя:** «Размер кольца» + «Базовое расстояние» + «Минимальный
> размер» вместе задают, как кольцо уменьшается с дистанцией: у источников ближе 8 м оно
> полное (96 px), дальше — плавно уменьшается до 12% размера. Хотите «дальше виднее» —
> увеличьте базовое расстояние и минимальный размер.

## Особенности и ограничения

- **Речь**: голосовой звук виден, когда его слышит хотя бы один NPC поблизости (второй
  собеседник, напарник, мутант). Одинокий сталкер, бормочущий сам с собой в пустом помещении,
  колец не даст — движок не рассылает «звук в никуда». В бою/на базе (типичные случаи)
  речь отображается.
- Кольца — **индикатор события**: они рисуются в точке, где прозвучал звук, и живут ~1 секунду.
  Идущий персонаж «следует» за собой цепочкой колец.
- В бою источников много: анти-спам и лимит одновременных волн (12) не дают экрану
  превратиться в кашу; настраивается паузой «от одного источника».
- Кольца не рисуются поверх инвентаря/диалогов/карты (HUD прячется при открытых меню).

## Совместимость

- Мод состоит **только из новых файлов** с уникальными именами (`sound_vision*`):
  перезаписей ванильных скриптов нет, конфликтов с другими аддонами не будет.
- Модифицированный `xr_danger.script` (Stealth Overhaul и т.п.) — совместимо: оба аддона
  лишь *добавляют* обработчики `npc_on_hear_callback`, они не мешают друг другу.
- Работает на ванильных экзешниках 1.5.1+; на modded exes тоже работает.

## Для разработчика

- Все константы пулинга — в начале `sound_vision.script`: `POOL = 24` (всего колец),
  `MOVE_POLL_MS = 250` (частота опроса движения), `MOVE_MIN_D2 = 0.06` (порог смещения).
- Добавить свой цвет/тип: дополните `KIND_COLOR` + `KIND_CAT` + `classify()` и добавьте
  чекбокс в `sound_vision_mcm.script` (не забудьте ключи в обоих текстовых XML).
- Классификация звука — по подстрокам типа из ogg-комментариев (`WPN_*`, `MST_*`, `NPC_step`,
  `voice`, `drop` и т.д.). Неизвестные типы попадают в «прочее» (синие).
- Отладка в игре: глобальная таблица `sound_vision_debug` — `.events` (текущая очередь
  событий), `.classify(s_type)` (классификатор), `.push_event(x, y, z, "step", nil)`
  (принудительно создать событие в точке).
